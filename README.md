# تمبيش - متجر ملابس إلكتروني
## Tembish - Online Clothing Store

متجر ملابس مرتب بي عنابة - منصة تسوق إلكترونية تقدم أحدث التصاميم بأسعار تنافسية

### المميزات:
- 🛍️ تصفح أقسام متنوعة (تي شيرتات، بناطيل، إلخ)
- 🚚 شحن سريع لجميع المناطق
- 💳 دفع آمن 100%
- ↩️ إرجاع سهل خلال 7 أيام
- 👥 خدمة عملاء 24/7

### البنية المشروع:
```
├── index.html          # الصفحة الرئيسية
├── css/
│   └── style.css      # تنسيقات الموقع
├── js/
│   ├── app.js         # تطبيق رئيسي
│   ├── products.js    # إدارة المنتجات
│   └── cart.js        # إدارة سلة التسوق
├── data/
│   └── products.json  # بيانات المنتجات
└── images/
    ├── products/      # صور المنتجات
    └── categories/    # صور الأقسام
```
